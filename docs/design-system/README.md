# Design System - Pámi

## Objetivo

El Design System define las reglas visuales y de experiencia de usuario del portal Pámi.

Su finalidad es garantizar que todas las páginas mantengan una identidad consistente, moderna y fácil de mantener.

Este documento forma parte del estándar Lyon Dev.

---

# Principios

El sistema debe ser:

- Consistente.
- Reutilizable.
- Accesible.
- Responsive.
- Escalable.
- Fácil de mantener.

# Filosofía Lyon Dev

Los componentes representan datos.

Las vistas contienen la lógica.

Los estilos siguen una única identidad visual.

Todo componente debe poder reutilizarse.

No se duplica HTML innecesariamente.

Tailwind CSS v4 es el framework oficial.
