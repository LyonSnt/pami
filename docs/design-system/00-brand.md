# Marca Pámi

## Nombre

Pámi

## Eslogan

Donde encuentras todo para ti.

El eslogan se obtiene desde `SiteConfiguration` y acompaña la marca en el header de tablet y escritorio. También se muestra en el footer para permanecer visible en todos los tamaños de pantalla.

Chaquetas y buzos hechos para ti.

## Logo

El logo oficial debe vivir en:

static/assets/branding/logo.svg

## Icono

El icono oficial debe vivir en:

static/assets/branding/icon.svg

## Recursos oficiales

- `logo.svg`: logo para fondos claros.
- `logo-white.svg`: logo para fondos oscuros.
- `icon.svg`: símbolo compacto de marca.
- `favicon.svg`: icono del navegador.
