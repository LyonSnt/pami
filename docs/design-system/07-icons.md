# Iconos

## Objetivo

Definir una iconografía consistente y accesible.

## Formato

Los iconos de interfaz utilizan SVG.

No se utilizan caracteres Unicode, emojis o símbolos de texto como sustituto permanente de un icono.

## Accesibilidad

- Los iconos decorativos utilizan `aria-hidden="true"`.
- Los iconos informativos deben tener un nombre accesible mediante texto visible o `aria-label` en el control.
- Un icono no reemplaza por sí solo el texto de una acción importante.

## Tamaños

Se priorizan tamaños de la escala Tailwind:

- `h-4 w-4`;
- `h-5 w-5`;
- `h-6 w-6`.

## Color

Los iconos institucionales utilizan `text-primary`. Los iconos secundarios utilizan la paleta `slate`.
